## 6. 故障排查（口试，必须答出）

请合上文档，回答下面问题。答不出 = 对应章节重读。

1. 启动报 `Could not resolve placeholder 'DEEPSEEK_API_KEY'`，怎么办？  
2. 依赖加了但找不到 `ChatClient`，最先检查 `pom.xml` 哪一段？  
3. 接口 401，配置前缀最可能写错成什么？  
4. 为什么讲义不让第一天就注入 `ChatModel`？（提示：2.0 日常 API 层次）  
5. Jackson 2 还是 3？DTO 用什么类型最省事？

**参考要点（自测后再看）：**

1. 设置环境变量或在 IDEA Run Configuration 添加；不要用空占位符启动。  
2. `dependencyManagement` 里的 `spring-ai-bom` 2.0.0 import。  
3. `spring.ai.openai.api-key` 等 OpenAI 前缀。  
4. `ChatClient` 是一等公民，封装提示、Advisor、消费端；`ChatModel` 是底层。  
5. Jackson **3**（Boot 4）；用 **record**。
