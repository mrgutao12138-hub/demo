# 01 · 环境准备

> 工欲善其事，必先利其器。  
> 本章把 JDK、Maven、IDEA 和环境变量一次配齐。配完请当场验证命令输出，**不要「我觉得装好了」**。

---

## 1. 版本要求（冻结）

| 工具 | 要求 | 说明 |
|---|---|---|
| JDK | **21 推荐**，最低 **17** | 讲义示例按 21 写；公司若锁 17 也可跑，但建议尽快升 21 |
| Maven | **3.9+** | 负责依赖解析与 `spring-boot:run` |
| IDE | IntelliJ IDEA（Community 即可） | 需支持 Java 21 与 Spring Boot 4 |
| 操作系统 | Windows / macOS / Linux 均可 | 下面三平台命令都给出 |

---

## 2. 安装 JDK 21

### 2.1 Windows

**方式 A：Oracle JDK / OpenJDK 安装包**

1. 从各发行商官网下载 **JDK 21** Windows x64 安装包并安装。
2. 安装完成后打开 **PowerShell**（或 CMD），执行：

```powershell
java -version
```

期望看到类似：

```
openjdk version "21.0.x" ...
```

3. 若 `java` 找不到，在「系统环境变量」里设置：

| 变量名 | 值（示例） |
|---|---|
| `JAVA_HOME` | `C:\Program Files\Java\jdk-21` |
| `Path` 追加 | `%JAVA_HOME%\bin` |

**方式 B：winget（已装 winget 的同学）**

```powershell
winget install Microsoft.OpenJDK.21
```

装完**重新开一个** PowerShell 窗口再验 `java -version`。

### 2.2 macOS

**方式 A：Homebrew（推荐）**

```bash
brew install openjdk@21
```

Apple Silicon 常见需要把 JDK 链到系统路径（Homebrew 安装结束时会提示，按提示执行即可）。典型做法：

```bash
sudo ln -sfn $(brew --prefix)/opt/openjdk@21/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk
```

验证：

```bash
java -version
```

**方式 B：公司软件中心 / 安装包**

若不能用 Homebrew，从公司 JDK 制品或 Adoptium/BellSoft 安装包安装 Temurin 21，把 `JAVA_HOME` 配进 `~/.zshrc`。不要在生产机上执行来路不明的远程安装脚本。

### 2.3 Linux（以 Ubuntu / Debian 为例）

```bash
sudo apt update
sudo apt install -y openjdk-21-jdk
java -version
```

Fedora / RHEL 系可用：

```bash
sudo dnf install -y java-21-openjdk-devel
java -version
```

### 2.4 【必做】JDK 验收

在终端执行：

```bash
java -version
javac -version
```

两条命令的主版本号都应是 **21**（或你刻意使用的 17）。不对就先别往下走。

## 3. 安装 Maven 3.9+

### 3.1 Windows

**方式 A：官方二进制包**

1. 从 Apache Maven 官网下载 3.9.x 二进制 zip，解压到例如 `C:\Tools\apache-maven-3.9.9`。
2. 环境变量：

| 变量名 | 值（示例） |
|---|---|
| `MAVEN_HOME` | `C:\Tools\apache-maven-3.9.9` |
| `Path` 追加 | `%MAVEN_HOME%\bin` |

3. 新开 PowerShell：

```powershell
mvn -version
```

**方式 B：Chocolatey**

```powershell
choco install maven
mvn -version
```

### 3.2 macOS

```bash
brew install maven
mvn -version
```

### 3.3 Linux

```bash
sudo apt install -y maven
# 或
sudo dnf install -y maven
mvn -version
```

若发行版自带的 Maven 低于 3.9，请从 Apache 官网下 3.9.x 手动解压，并把 `bin` 目录加入 `PATH`。

### 3.4 【必做】Maven 验收

```bash
mvn -version
```

确认：

- Apache Maven **3.9.x**（或更高）
- Java version 指向你的 JDK 21

### 3.5 【建议】配置国内镜像（下载慢的同学）

编辑用户目录下的 `~/.m2/settings.xml`（没有就新建）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings xmlns="http://maven.apache.org/SETTINGS/1.2.0"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.2.0
          https://maven.apache.org/xsd/settings-1.2.0.xsd">
  <mirrors>
    <mirror>
      <id>aliyunmaven</id>
      <mirrorOf>central</mirrorOf>
      <name>Aliyun Maven</name>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

公司内网有私服的同学，以运维提供的 `settings.xml` 为准。

## 4. 安装 IntelliJ IDEA

### 4.1 下载与安装

1. 安装 **IntelliJ IDEA Community** 或 Ultimate（社区版足够本章）。
2. 首次启动时安装插件：**Spring Boot**（通常已内置）。

### 4.2 【必做】IDEA 指向 JDK 21

1. `File` → `Project Structure` → `SDKs`：添加 JDK 21 路径。
2. `File` → `Settings` → `Build, Execution, Deployment` → `Build Tools` → `Maven`：
   - **Maven home path**：指向你的 Maven 3.9+
   - **User settings file**：若用了镜像，指到 `settings.xml`

### 4.3 【建议】启用注解处理

后面章节会用到配置类；提前打开：

`Settings` → `Build, Execution, Deployment` → `Compiler` → `Annotation Processors` → 勾选 **Enable annotation processing**。

## 5. 配置 DeepSeek API Key 环境变量

Key 的具体申请流程在 `02-DeepSeek账号密钥与计费.md`。这里先教你怎么**放进系统环境变量**，让 Spring 能读到 `${DEEPSEEK_API_KEY}`。

变量名固定：**`DEEPSEEK_API_KEY`**  
变量值：你在 DeepSeek 开放平台控制台复制的 Key（形如 `sk-...`）。

### 5.1 Windows（当前用户，持久）

PowerShell：

```powershell
[System.Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "sk-你的密钥", "User")
```

关闭并**重新打开**终端，验证：

```powershell
echo $env:DEEPSEEK_API_KEY
```

应输出你的 Key（注意周围没人偷看屏幕）。

图形界面：「设置」→「系统」→「关于」→「高级系统设置」→「环境变量」→ 用户变量 → 新建 `DEEPSEEK_API_KEY`。

### 5.2 macOS / Linux（当前 shell 会话，临时）

```bash
export DEEPSEEK_API_KEY="sk-你的密钥"
echo $DEEPSEEK_API_KEY
```

### 5.3 macOS / Linux（持久，推荐）

**bash**（`~/.bashrc` 或 `~/.bash_profile`）：

```bash
echo 'export DEEPSEEK_API_KEY="sk-你的密钥"' >> ~/.bashrc
source ~/.bashrc
```

**zsh**（macOS 默认，`~/.zshrc`）：

```bash
echo 'export DEEPSEEK_API_KEY="sk-你的密钥"' >> ~/.zshrc
source ~/.zshrc
```

验证：

```bash
echo $DEEPSEEK_API_KEY
```

### 5.4 IDEA 里跑应用时读不到环境变量？

在 Run Configuration 里添加环境变量：

1. `Run` → `Edit Configurations`
2. 选中你的 Spring Boot 启动项
3. **Environment variables** 添加：`DEEPSEEK_API_KEY=sk-你的密钥`

【红线】不要把真实 Key 写进 `application.yml` 再提交 Git。环境变量或 IDEA 本地 Run Configuration（不提交）才是正路。

## 6. 网络与代理（【建议】）

DeepSeek API 默认地址是 `https://api.deepseek.com`。公司网络若需代理，在启动前设置（示例）：

**macOS / Linux：**

```bash
export HTTPS_PROXY="http://代理地址:端口"
export HTTP_PROXY="http://代理地址:端口"
```

**Windows PowerShell：**

```powershell
$env:HTTPS_PROXY="http://代理地址:端口"
$env:HTTP_PROXY="http://代理地址:端口"
```

若完全无法访问外网，本章无法完成云端调用；需联系网络管理员放行，或等扩展篇的内网模型方案。

## 7. 【必做】环境自检清单

请逐项执行，全部通过再进入下一章：

1. `java -version` → 主版本 **21**（或你确认的 17+）。
2. `javac -version` → 与 `java` 一致。
3. `mvn -version` → Maven **3.9+**，且 Java 版本正确。
4. `echo $DEEPSEEK_API_KEY`（Windows 用 `echo $env:DEEPSEEK_API_KEY`）→ 能输出 Key（先占位也行，下一章再换真 Key）。
5. IDEA 已安装，Project SDK 指向 JDK 21。

---

## 8. 常见卡点

| 现象 | 原因 | 处理 |
|---|---|---|
| `java` 仍是 1.8 | `PATH` 里旧 JDK 在前 | 调整 `JAVA_HOME` 与 `Path` 顺序 |
| Maven 用的 Java 8 | `JAVA_HOME` 未设 | 设好 `JAVA_HOME` 后重开终端 |
| IDEA 终端读不到 `DEEPSEEK_API_KEY` | 变量在装 IDEA 之前设的，或只写在 shell rc 里没重启 IDE | 重开 IDEA，或在 Run Configuration 里显式添加 |
| `mvn` 下载极慢 | 未配镜像 | 见 3.5 节 |
