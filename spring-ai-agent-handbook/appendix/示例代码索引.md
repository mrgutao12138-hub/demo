## 使用说明

1. **先找 part，再找讲义文件名**，在对应 `.md` 里搜 ` ```java ` 代码块。
2. 带 **【完整】** 标记的，表示该文件含可独立运行的端到端片段（或整文件 pom）。
3. 综合项目 part-08 代码在你自己仓库；讲义提供 **清单** 与 **包结构**，不替代你的业务实现。

## 最小决策 Agent 类清单

> 从 part-04 到可演示 part-08 的 **Java 类型最小集合**。名字可改，职责不要删。

### 1. 启动与配置

| 类 / 文件 | 职责 |
|---|---|
| `DecisionAgentApplication` | `@SpringBootApplication` 入口 |
| `pom.xml` | 见 `appendix/pom完整模板.md` 模板 B |
| `application.yml` | `spring.ai.deepseek.*`、数据源、可选 pgvector |
| `ChatClientConfig` | `defaultSystem`、flash/pro 双 `ChatClient` |
| `AdvisorChainConfig` | 注册 Memory、RAG、Tool 顺序 |

### 2. Web 入口

| 类 | 职责 |
|---|---|
| `ChatController` | 同步/流式 API；生成并传递 `CONVERSATION_ID` |
| `AuditController` | 管理员查审计流水（part-08） |

### 3. Agent 编排

| 类 | 职责 |
|---|---|
| `DecisionCopilotService` | 统一 `chatClient.prompt()...`；意图粗分；组装响应 DTO |
| `IntentRouter`（可选） | 简单规则或 flash 模型判断走查数还是闲聊 |

### 4. 工具层（只读）

| 类 | 职责 |
|---|---|
| `InventoryTools` | `getSku`、`queryInventory`、`compareWarehouses` |
| `PurchaseTools` | `queryOverduePurchaseOrders` 等 |
| `EmsTools` | `queryDowntime` 等 |
| `*Repository` / `JdbcClient` | 固定 SQL + 参数白名单 + 租户过滤 |

### 5. RAG

| 类 | 职责 |
|---|---|
| `KnowledgeIngestionJob` | 启动或定时：切分 → embed → `vectorStore.add` |
| `VectorStoreConfig` | `SimpleVectorStore` 或 pgvector Bean |
| `EmbeddingConfig` | `TransformersEmbeddingModel` 或等价 |

### 6. 安全与观测

| 类 | 职责 |
|---|---|
| `TenantContext` / `UserContext` | 当前用户、仓、租户 |
| `AgentAuditAspect` 或 `AuditAdvisor` | 记录问题、工具、token |
| `SecurityConfig` | 登录、角色、API 鉴权 |

### 7. 领域 DTO

| 类 | 职责 |
|---|---|
| `DecisionResponse`（record） | 结论 / 数字 / 依据 / 风险 / 建议 |
| `SourceCard`（record） | 来源类型（TOOL/RAG）、标题、时间、过滤条件 |
| `MetricResult` | 数值 + `asOf` + 指标字典 id |

### 8. 测试与评测

| 资源 | 职责 |
|---|---|
| `evaluation-set.json` | ≥20 条问答 + 期望行为标签 |
| `AgentIntegrationTest` | 三必测问 + 拒写 + 越权 |
