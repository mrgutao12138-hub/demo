## 2. 练习 P1：同步决策问答

**要求：**

1. 使用 `DecisionSystemPrompt`（第 02 节长模板）作为 system；
2. 运行时注入 `tenantName`、`userRole`、`dataAsOf`；
3. 暴露 `POST /api/lab/p1/ask`。

**参考实现：**

```java
package com.example.agent.lab.part03;

import com.example.agent.prompt.DecisionSystemPrompt;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/lab/p1")
public class P1SyncAskController {

    private final ChatClient decisionChatClient;

    public P1SyncAskController(@Qualifier("decisionChatClient") ChatClient decisionChatClient) {
        this.decisionChatClient = decisionChatClient;
    }

    public record Request(String tenant, String role, String dataAsOf, String question) {}

    @PostMapping("/ask")
    public String ask(@RequestBody Request req) {
        return decisionChatClient.prompt()
                .system(s -> s.text(DecisionSystemPrompt.TEXT)
                        .param("tenantName", req.tenant())
                        .param("userRole", req.role())
                        .param("dataAsOf", req.dataAsOf()))
                .user(req.question())
                .call()
                .content();
    }
}
```

**自测：** 问「SKU-88321 库存多少」——模型应拒绝编造，提示需要数据/工具（part-04 再接真工具）。

## 3. 练习 P2：SSE 流式

**要求：**

1. `GET /api/lab/p2/stream?message=...`；
2. `produces = TEXT_EVENT_STREAM`；
3. 使用 `decisionChatClient` 的 `stream().content()`。

```java
package com.example.agent.lab.part03;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import reactor.core.publisher.Flux;

@RestController
@RequestMapping("/api/lab/p2")
public class P2StreamController {

    private final ChatClient decisionChatClient;

    public P2StreamController(@Qualifier("decisionChatClient") ChatClient decisionChatClient) {
        this.decisionChatClient = decisionChatClient;
    }

    @GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<String> stream(@RequestParam String message) {
        return decisionChatClient.prompt()
                .user(message)
                .stream()
                .content();
    }
}
```

**自测：**


## 4. 练习 P3：结构化摘要

**要求：**

1. 定义 `DecisionSummary` record；
2. `POST /api/lab/p3/summary`；
3. 使用 `.entity(..., spec -> spec.validateSchema())`；
4. 模板中含 JSON 字段说明时，用 `<>` 分隔符（第 04 节）。

```java
package com.example.agent.lab.part03;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.List;

@RestController
@RequestMapping("/api/lab/p3")
public class P3StructuredController {

    private final ChatClient decisionChatClient;

    public record SummaryRequest(String scenario) {}

    public record DecisionSummary(
            String conclusion,
            List<String> keyFacts,
            List<String> risks,
            List<String> recommendedActions
    ) {}

    public P3StructuredController(@Qualifier("decisionChatClient") ChatClient decisionChatClient) {
        this.decisionChatClient = decisionChatClient;
    }

    @PostMapping("/summary")
    public DecisionSummary summary(@RequestBody SummaryRequest req) {
        return decisionChatClient.prompt()
                .system("""
                        根据用户描述的业务场景生成决策摘要 JSON。
                        字段：conclusion, keyFacts, risks, recommendedActions。
                        不要编造具体数字；无数据则在 risks 中说明。
                        """)
                .user(req.scenario())
                .call()
                .entity(DecisionSummary.class, spec -> spec
                        .useProviderStructuredOutput()
                        .validateSchema());
    }
}
```

## 5. 练习 P4：会话记忆

**要求：**

1. 配置 `MessageChatMemoryAdvisor` 为 `defaultAdvisors`；
2. 每次请求传 `conversationId`；
3. 同一 ID 第二轮能引用第一轮内容。

```java
package com.example.agent.lab.part03;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.memory.ChatMemory;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/lab/p4")
public class P4MemoryController {

    private final ChatClient advisedChatClient;  // 第 06 节配置了 Memory Advisor 的 Bean

    public record MemoryRequest(String conversationId, String message) {}

    public P4MemoryController(ChatClient advisedChatClient) {
        this.advisedChatClient = advisedChatClient;
    }

    @PostMapping("/chat")
    public String chat(@RequestBody MemoryRequest req) {
        return advisedChatClient.prompt()
                .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, req.conversationId()))
                .user(req.message())
                .call()
                .content();
    }
}
```

**自测：**

1. `conversationId=test-001`，message=`我叫张三，负责华东仓。`
2. 同一 ID，message=`我刚才说我叫什么？负责哪？`

应能答出张三与华东仓。

## 7. 练习 P6（加分）：推理内容落库

**要求：**

1. 用 `decisionChatClient` 开启 thinking；
2. `chatResponse()` 取 `DeepSeekAssistantMessage`；
3. 返回 `{ "reasoning": "...", "answer": "..." }`（推理默认不展示给终端用户时可只写日志）。

```java
package com.example.agent.lab.part03;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.ai.deepseek.DeepSeekAssistantMessage;
import org.springframework.ai.deepseek.DeepSeekChatOptions;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/lab/p6")
public class P6ReasoningController {

    private final ChatClient decisionChatClient;

    public record ReasoningRequest(String question) {}

    public record ReasoningResponse(String reasoning, String answer) {}

    public P6ReasoningController(@Qualifier("decisionChatClient") ChatClient decisionChatClient) {
        this.decisionChatClient = decisionChatClient;
    }

    @PostMapping("/reason")
    public ReasoningResponse reason(@RequestBody ReasoningRequest req) {
        ChatResponse response = decisionChatClient.prompt()
                .options(DeepSeekChatOptions.builder()
                        .enableThinking()
                        .reasoningEffortHigh()
                        .build())
                .user(req.question())
                .call()
                .chatResponse();

        var output = response.getResult().getOutput();
        if (output instanceof DeepSeekAssistantMessage msg) {
            return new ReasoningResponse(msg.getReasoningContent(), msg.getText());
        }
        return new ReasoningResponse(null, output.getText());
    }
}
```

## 10. 常见作业翻车点

| 现象 | 排查 |
|---|---|
| 记忆第二轮失忆 | 是否同一 `conversationId`？是否忘了 `.param()`？ |
| 流式没输出 | 是否引 webflux？是否用 `curl -N`？ |
| 结构化解析失败 | 开 `validateSchema()`；检查 record 字段名与模型输出 |
| 两个 ChatClient 注入报错 | `@Qualifier` 或 `@Primary` |
| 观测数据缺失 | 是否绕过了 `ChatClientBuilderConfigurer`？ |
