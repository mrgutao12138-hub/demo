# 06 · 制度、SOP、口径知识库怎么建

> 向量库不是垃圾桶。这一章给你 **5 篇完整假制度 Markdown**，可直接放进 `src/main/resources/knowledge/policies/` 做入库实验。

---

## 1. 知识库建设流程

```
1. 盘点文档类型（制度 / SOP / 指标字典）
2. 统一 Markdown 模板 + 文件头元数据
3. 按标题切分（02、04 DocumentIngestion）
4. 评审：业务 + 财务 + 合规签字
5. CI 任务：ingest → pgvector
6. 评测集：20～50 个口径问答，定期回归
```

---

## 2. 文件头元数据规范

每篇制度顶部用 `---` 块，供 `DocumentIngestion` 解析：

```markdown
---
docId: INV-POL-2024-01
title: 库存管理制度
effectiveDate: 2024-03-01
org: east-china
warehouse: ALL
type: policy
---
```

| 字段 | 必填 | 说明 |
|---|---|---|
| docId | 是 | 全局唯一编号 |
| title | 是 | 文档名称 |
| effectiveDate | 是 | 生效日期 ISO |
| org | 是 | 法人/区域；全集团 `ALL` |
| warehouse | 是 | 仓库；不适用填 `ALL` |
| type | 是 | `policy` / `sop` / `glossary` |

正文用 `##`、`###` 分章，**禁止**整篇无标题堆砌。

### 范文 1：库存管理制度（含可用量口径）

保存为：`INV-POL-2024-01-库存管理制度.md`

```markdown
---
docId: INV-POL-2024-01
title: 库存管理制度
effectiveDate: 2024-03-01
org: east-china
warehouse: ALL
type: policy
---

# 库存管理制度（华东区域）

## 1. 目的与适用范围

本制度适用于华东区域（org: east-china）所有自营仓库的库存统计、可用量发布与决策引用。海外仓、代销仓不适用，除非总部书面追加。

## 2. 术语

### 2.1 账面库存

指 WMS 中「在库」状态 SKU 的实物数量合计，含待检、冻结、预留子状态，但在可用量计算中须按本章公式扣减。

### 2.2 销售预留

指 ERP 已确认但未发货的销售订单占用量，状态为「已审核未出库」的锁定数量。

## 3. 库存可用量

### 3.1 定义

**库存可用量**指在当前时点，可供新销售订单分配、且不被制度禁止动用的数量。

### 3.2 计算公式

可用量 = 账面库存 − 销售预留 − 质检待放行占用 − 库内冻结 − 跨仓调拨在途占用（调出方）

说明：

- **质检待放行占用**：已完成收货但质检结论未出的数量，**不计入可用量**，直至质检合格放行。
- **库内冻结**：因盘点差异、客诉封存、监管要求冻结的数量，不计入可用量。
- **跨仓调拨在途**：调出仓已扣账、调入仓未收货部分，调出方扣减，调入方在收货前不计入可用量。

### 3.3 例外情形

- 总部特批的「预售可用」标识 SKU，可用量可包含在途采购已到货未入账部分，但须在报表脚注标明「含预售口径」。
- 样品仓（warehouse: WH-SAMPLE）不适用本公式，样品仅展示不销售。

## 4. 发布与变更

可用量口径变更须提前 15 个工作日通知财务与销售；本制度版本以 docId 与 effectiveDate 为准。
```

### 范文 2：采购管理制度（含超期采购定义）

保存为：`PUR-POL-2024-02-采购管理制度.md`

```markdown
---
docId: PUR-POL-2024-02
title: 采购管理制度
effectiveDate: 2024-04-01
org: east-china
warehouse: ALL
type: policy
---

# 采购管理制度（华东区域）

## 1. 目的

规范采购订单全生命周期，明确超期采购的统计口径，供管理层决策与考核使用。

## 2. 超期采购

### 2.1 定义

**超期采购订单**指同时满足以下条件的采购订单行（PO Line）：

1. 订单状态为「已审核」且未完成关闭；
2. 当前日期 > 约定到货日期（Promised Date）+ **宽限期 3 个自然日**；
3. 该行**未收货数量 > 0**（含部分收货未结清情形）。

### 2.2 不计入超期的情形

- 供应商已提交延期申请且采购员在 ERP 中更新了新 Promised Date，并以新日期计算是否超期。
- 因不可抗力（地震、重大疫情）经供应链委员会备案的订单，在备案有效期内暂停超期统计。
- **在途已发货**但仓内未收货：仍计入超期，除非满足上款延期备案。

### 2.3 在途与超期的关系

「在途」描述物流状态；「超期」描述交期违约。在途订单可以是超期订单，也可以未超期。决策系统展示超期列表时，须同时显示：未收货数量、原约定到货日、当前 Promised Date、是否在途。

## 3. 考核

采购员 KPI 中超期金额占比，按本章 2.1 口径每月结账后 T+3 日发布，不得使用未审核订单或已关闭订单充数。
```

### 范文 3：仓库作业 SOP（华东上海仓）

保存为：`SOP-WH-SH-01-收货冻结.md`

```markdown
---
docId: SOP-WH-SH-01
title: 上海仓收货与质检冻结作业指导
effectiveDate: 2024-05-01
org: east-china
warehouse: WH-SH-01
type: sop
---

# 上海仓（WH-SH-01）收货与质检冻结 SOP

## 1. 适用范围

本 SOP 仅适用于上海浦东仓 WH-SH-01，与集团通用制度冲突时，以**更严格**条款为准。

## 2. 收货入账

### 2.1 标准流程

到货扫描 → 收货单生成 → 账面库存增加 → 子状态置为「待检」。

### 2.2 与可用量的关系

待检子状态数量在收货入账当日即参与 **账面库存**，但**不参与可用量**（见 INV-POL-2024-01 第 3.2 节）。

## 3. 质检放行

质检合格：子状态改为「合格可售」，当日批次可用量自动增加。

质检不合格：转入隔离区，触发 PUR-POL 不合格品处理流程，可用量不恢复直至处置完成。

## 4. 时效

普通物料质检 SLA：收货后 **48 小时**内出具结论；冷链物料 **12 小时**。超 SLA 未检完，系统向仓库主管推送预警，但不改变可用量公式。
```

warehouse: ALL
type: policy
---

# 库存管理制度（华南区域）

## 3. 库存可用量

### 3.2 计算公式（华南）

可用量 = 账面库存 − 销售预留 − 库内冻结

**与华东差异**：华南区域 **不单独扣除质检待放行占用**；待检数量在质检结论出具前**暂计可用**，但不得超过该 SKU 近 30 天日均销量的 3 倍安全上限。超出上限部分系统自动冻结为「待检预占」。

### 3.3 引用说明

华东区域请使用 docId INV-POL-2024-01。本文件仅 org: south-china 生效。

### 范文 5：决策指标口径字典

保存为：`GLOSSARY-2024-指标字典.md`

```markdown
---
docId: GLOSSARY-2024
title: 供应链决策指标口径字典
effectiveDate: 2024-01-01
org: ALL
warehouse: ALL
type: glossary
---

# 供应链决策指标口径字典

## 指标：库存周转天数

**定义**：统计期间平均库存金额 /（统计期间销售成本 / 统计天数）。

**数据源**：ERP 存货核算模块，不含代销库存。

**禁止**：用采购入库金额代替销售成本。

## 指标：超期采购金额

**定义**：按 PUR-POL-2024-02 识别的超期 PO 行，以其**未收货数量 × 订单单价**（不含税）汇总。

**禁止**：将已关闭订单、已全额收货订单计入。

## 指标：可用量满足率

**定义**：有货可配的订单行数 / 当期申请分配订单行数。

**分子判定**：该行分配时点的可用量 ≥ 申请量，且符合该区域可用量制度（华东见 INV-POL-2024-01，华南见 INV-POL-2024-01-SC）。
```

## 6. 治理与版本

- 制度变更：**新 effectiveDate**，旧版可保留在库，检索时过滤最新。  
- 废止：从向量库按 `docId` 删除，勿只改文件名不 re-index。  
- 权限：绝密文档不进同一 VectorStore，或单独 collection + 强过滤。
