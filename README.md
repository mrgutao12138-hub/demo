# 学习资料

本仓库是一份给 Java 工程师的 **Spring AI Agent 手把手讲义**，目标是：跟着学完后，能独立搭建 AI Agent，并具备把 ERP / WMS / EMS 做成管理层辅助决策系统的完整知识结构。

技术路线固定为 **Java + Spring Boot + Spring AI**，不走 Python。

## 从这里开始

- 学完必须能独立做到的 8 件事

- 可复制的 Spring AI 代码
- 工具调用、记忆、RAG、Agent 循环
- 对接企业数据库时为什么不能让模型直接写 SQL
- 安全、评估、上线检查
- 毕业自测与排错手册
